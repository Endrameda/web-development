# Tools

> Tools are the only way Claude Code touches anything: every file read, search, edit, shell command and delegation is a named tool call, and that same exact name is what permission rules, subagent `tools` lists, hook matchers and skill `allowed-tools` all key on.

## Base tools

Names are exact strings. "Prompts" is the docs' manual-mode column for paths inside the working directory.

| Group    | Tool                                  | What it does                                              | Prompts |
| -------- | ------------------------------------- | --------------------------------------------------------- | ------- |
| Read     | `Read`                                | File contents with line numbers; also images, PDFs, notebooks. Files only, not directories | No      |
| Search   | `Glob`                                | Find files by name pattern (see Gotchas: not always present) | No      |
| Search   | `Grep`                                | Search file contents, ripgrep syntax (same caveat)        | No      |
| Search   | `LSP`                                 | Definitions, references, type errors via language servers | No      |
| Modify   | `Edit`                                | Targeted edits to a file                                  | Yes     |
| Modify   | `Write`                               | Create or overwrite a file                                | Yes     |
| Modify   | `NotebookEdit`                        | Edit Jupyter cells                                        | Yes     |
| Execute  | `Bash` (`PowerShell` on Windows)      | Run shell commands                                        | Yes     |
| Execute  | `Monitor`                             | Run a command in the background, feed output lines back   | Yes     |
| Web      | `WebFetch`, `WebSearch`               | Fetch a URL / search the web                              | Yes     |
| Delegate | `Agent`                               | Spawn a [subagent](../subagents/0.%20Subagents.md)        | No      |
| Delegate | `Skill`                               | Run a [skill](../skills/0.%20Skills.md)                   | Yes     |
| Delegate | `Workflow`                            | Script that orchestrates many subagents in the background | Yes     |
| Plan     | `TaskCreate`/`TaskUpdate`/`TaskList`/`TaskGet` | Session task list (model-dependent availability) | No      |
| Ask      | `AskUserQuestion`, `EnterPlanMode`, `ExitPlanMode` | Clarify, switch into plan mode, present a plan | No / No / Yes |

The full table has more (cron, worktree, messaging, MCP resource tools). This one is the subset that matters when deciding what an agent may do.

## Gotchas

- **`Glob` and `Grep` are absent by default on macOS, Linux and WSL.** Claude searches with `find` and `grep` through `Bash` instead (embedded `bfs` and `ugrep`), so those searches reach hooks and permission rules as `Bash` calls. They come back if you name them in `--tools` / `--allowedTools`, or if Bash is removed. For a subagent: listing `Glob`/`Grep` in `tools` *and leaving out `Bash`* restores them for that subagent. List them next to `Bash` and they stay absent.
- **A tool listed but not available is silently not granted.** For subagents the resolved set is capped at the tools available to subagents. `AskUserQuestion`, `EnterPlanMode`, `ExitPlanMode` (unless `permissionMode: plan`) and `Workflow` are always removed from them.
- **"No prompt" is not "no limit".** `Read`, `Grep`, `Glob` still prompt for paths outside the working directory and added directories. `Bash` runs a built-in set of read-only commands without prompting.
- **`Bash` can do whatever `Edit` and `Write` can.** Leaving the edit tools off a tool list is not a read-only guarantee while `Bash` is on it.
- **Rule format is shared.** `ToolName(specifier)` works in `permissions.allow/deny`, `--allowedTools`, skill `allowed-tools` and hook `if` conditions. The specifier's meaning depends on the tool.
- **Task tools depend on the model.** Default on a fixed list of models, opt-in on others. A subagent only gets them if the session has them.
- **To see what is really loaded, ask Claude, or run `/mcp` for MCP tool names.** The set varies by provider, platform and settings.
