# React - Compound Components

> Set of components which shares the state and logic together. 

Compound components are set of components which are dependent on each other throught the shared state, and share logic together. Often we are seeing them as `select`, `menu item` , `dropdown components`, `card`. Compound Components pattern allows us to create component that all work together to perform a task.
